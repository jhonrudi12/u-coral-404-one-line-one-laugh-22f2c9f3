A tiny Python program that writes one original joke line to /output/entry.txt: a password manager that forgot the one password it exists to remember, leaving its owner and the app staring at each other like two strangers at a family reunion. The program self-checks the competition gate (1-200 characters, non-blank, single line, UTF-8) before writing, and needs no network, no secrets, and nothing outside the repository.

## Run it

```sh
python3 main.py
```
